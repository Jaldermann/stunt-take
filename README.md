# Stunt Take

A side-scrolling action game for phones (and desktops). You're the stunt double; every fall is on camera.

- Three film sets: Dusty Gulch (western), Neon 2099 (sci-fi), Lost Temple (jungle + boss).
- 3 takes per scene. Die and the director yells **CUT!**
- Touch: ◀ ▶ bottom-left, JUMP / PUNCH bottom-right. Keyboard: arrows/A D, Space jump, J/X punch, P pause, M mute.

Single self-contained `index.html`, no dependencies. `node check.mjs` runs the smoke + level-reachability checks.
